# Grocery Store Management System (C++) 🛒💻  
![C++](https://img.shields.io/badge/Language-C%2B%2B-blue)

This is a **Grocery Store Management System** developed in **C++**. The application allows users to manage products, place orders, and generate bills with an easy-to-use interface.

---

## Features 🚀

- **Product Management:** Add, Update, Delete, and Search products.
- **Order Placement:** Place orders and generate a detailed bill.
- **File Handling:** Stores product data in a file and retrieves it for operations.
- **Simple Text-Based Interface:** Easy-to-navigate menu for normal users and developers.

---

## User Guide 📚

### For Normal Users

1. **Start the App:** Run the C++ application. A menu will be presented to you.
2. **Menu Options:**
   - **Create Products:** Add new products to the store.
   - **Display Products:** View all available products.
   - **Search Products:** Search for a product by its product number.
   - **Modify Products:** Update product details.
   - **Delete Products:** Remove a product from the store.
   - **Place an Order:** Place orders for products with the required quantity.
   - **Exit:** Exit the application.
3. **Place an Order:** After selecting "Place an Order", enter the product number and quantity. The total amount and bill will be shown.

### For Developers

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/aayush61203/Grocery-Store-Management-System-C.git
   ```
2. **Compile the Code:** Use any C++ compiler (e.g., **G++**) to compile the code:
   ```bash
   g++ main.cpp -o grocery_store
   ```
3. **Run the Program:** After compiling, run the program using:
   ```bash
   ./grocery_store
   ```
4. **Make Changes:** 
   - Modify the C++ code as needed (e.g., add new features, fix bugs).
   - Update product details or handle more complex inventory operations.
5. **Commit and Push Changes:** After making modifications, commit your changes and push them to the repository.

## Code Structure 🗂️

- **main.cpp:** The main file that contains all the functionality of the grocery store management system.
